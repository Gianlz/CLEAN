# Changelog

## 0.1.0 - 2026-08-11

### Added

- Animated Ratatui interface with responsive, no-color, and reduced-motion modes.
- Read-only scans for `~/Library/Caches` and `~/.cache`.
- Seven-day age protection with an explicit recent-file override.
- Group selection with no automatic preselection.
- Exact typed confirmation before permanent deletion.
- Manifest identity revalidation and descriptor-anchored, no-follow file removal.
- Cancellation, post-clean rescan, and detailed cleanup receipts.
- Temporary-fixture regression tests for mutation, symlink escape, hard links, cancellation, and root boundaries.
